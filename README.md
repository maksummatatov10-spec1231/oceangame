# Ocean Voyage

Небольшая законченная 3D-игра для **Godot 4.3**: моряк стоит на палубе корабля, корабль ходит по анимированному океану, а цель игрока — найти четыре золотых маяка у островов.

## Запуск

1. Откройте эту папку в Godot 4.3 (Project Manager → **Import** → `project.godot`).
2. Нажмите **F6/F5**.

> Проект намеренно использует `gl_compatibility`, поэтому запускается и на не слишком мощных видеокартах. Для более красивого освещения в настройках проекта можно сменить renderer на Forward+.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W` / `↑` | идти вперёд |
| `S` / `↓` | задний ход |
| `A` / `←` | повернуть влево |
| `D` / `→` | повернуть вправо |
| `Shift` | полный парус |
| `R` | начать плавание заново |

## Что было в трёх архивах

Архивы были проверены по отдельности: это **не части одного split-ZIP**, а три самостоятельных ZIP-файла.

- `ассеты1.zip` (9.2 КБ) — исходный проект Godot 4.0: сцены океана, простая капсула-персонаж, бесконечная сетка из 17 водных тайлов, `Water.gdshader` и настройки управления.
- `ассеты2.zip` (19 МБ) — панорама закатного неба `Resources/AllSkyFree_Sky_EpicBlueSunset_Equirect.png` (19 472 329 байт) и ресурс параметров сетки океана.
- `ассеты3.zip` (13 МБ) — отдельная панорама ночного неба `AllSkyFree_Sky_MoonBurst_Equirect.png` (13 408 490 байт).

Исходный проект уже был ориентирован на Godot 4, однако был скорее техническим демо: не было корабля, игровой цели, интерфейса или полноценной игровой сцены. В этой версии он переработан в самостоятельную игру: добавлены корабль и моряк, острова, цели, камера, HUD, управление с ускорением и новый лёгкий шейдер волн. Небо сделано процедурным, чтобы проект запускался сразу, не распаковывая 32 МБ дубликатов из архивов. Оригинальные панорамы сохранены в репозитории в ZIP и могут быть распакованы при желании для замены ProceduralSky в `scripts/ocean_game.gd`.

## Структура новой игры

- `Main.tscn` — стартовая сцена.
- `scripts/ocean_game.gd` — генерация мира, корабль, персонаж, камера, HUD и игровой цикл.
- `shaders/ocean.gdshader` — волны, блики и цвет глубокого океана.
